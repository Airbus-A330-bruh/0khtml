0k Pr0xy - HTML File version

- Modified Version of 0k (original 0k can be found here: https://github.com/abndnce/0k)
- Made by Claude, with
  checks and tests performed by me.
- Uses virtual service workers
- Designed to replace GUST and Sandstone
- Supports a number of sites, with more being patched frequently.
  
Why HTML? 
- Ultra-Portability
- Stealth
  
ROADMAP + CURRENT PROGRESS
- Geofs support (implemented already, only seems to support 4.0)
- Veck.io (fully supported)
- Monochrome.st (Partially supported, basic functions operational. Full support planned)
- Gn Math (Partial support, many games still need substantial patches. Actively being worked on)
- Yandex.com/games (partial support, MUCH work needed)
- Aether.st and Cinecat.eu (non functional, video playback buffers endlessly)
